# Contributing

Open an issue to describe a bug or propose a source adapter. Include the public board URL, expected behavior, and a minimal reproduction. Never include tokens, mailbox content, CVs, contact details, or private configuration.

For changes, install the development dependencies and run `python -m pytest -q`. Add a mocked response test for each new adapter or parsing fix. Keep source failures visible and preserve original application URLs. Public endpoints should require no login or account cookies. Follow the source's terms and limits.
